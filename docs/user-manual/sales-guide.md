# 销售人员手册

本指南专为 **销售人员** 设计，介绍如何使用移动端销售系统进行开单、查询和客户维护。

## 1. 登录系统

### 访问地址
https://your-domain.pages.dev/pages/sales/login.html

### 登录方式
1. **密码登录**: 使用管理员分配的账号和密码 (首次登录必需)。
2. **微信一键登录**: 绑定微信后，可直接通过小程序或微信环境内的一键登录按钮进入。

### 绑定微信
为了方便后续快速登录：
1. 使用账号密码登录系统。
2. 进入 **个人中心** -> **绑定微信**。
3. 按照提示点击“确认绑定”。
4. 下次访问即可直接使用“微信登录”。

## 2. 订单管理

### 创建新订单 (开单)
1. 点击底部的 **"+" (加号)** 按钮。
2. 填写客户信息 (姓名、电话)。
3. 选择商品/输入定制需求 (尺寸、材质、颜色等)。
4. **填写数量**: 输入订单商品数量 (默认为 1)。
5. **上传附件**: 点击上传按钮，选择手机相册中的参考图或设计草图。
5. 点击 **提交订单**。
   - 订单将进入 `Pending` (待确认) 状态。

### V2 错误恢复指引（2026-03）
销售端已启用新版订单流程（V2），在网络波动或接口失败时，页面会显示明确恢复入口：

1. **列表加载失败**:
   - 页面会显示“重试”按钮，可直接重新拉取订单列表。
2. **商品选择失败**:
   - 商品绑定区域会出现内联错误提示，点击“重试”即可再次拉取。
3. **提交失败**:
   - 表单内容会保留，不会静默丢失；页面会显示错误提示与恢复动作。
4. **详情页异常**:
   - 详情页会显示统一错误态，可一键重试加载。
5. **评论发送失败**:
   - 输入内容会保留，并提供重试按钮。

### 查看订单
在 **订单列表** 页，可以：
- 按状态筛选 (待确认、生产中、已发货)。
- 点击卡片查看订单详情、时间轴和附件。
- 下滑加载更多历史订单。

在 **订单详情** 页，当前还可能看到更细的采购进度提示，例如：

- 已下单
- 部分到货
- 全部到货

如果出现“部分到货”，通常表示供应链已经先到了一部分货，并不代表整单异常。

### 修正/更新订单
- 如果订单处于 `Pending` 状态，您可以点击 **编辑** 按钮修改信息。
- 如果订单已被管理员确认 (Confirmed)，则无法直接修改，请联系管理员或在订单详情页 **添加评论** 说明变更需求。

## 3. 常见问题

**Q: 忘记密码怎么办？**
A: 请联系各门店店长或系统管理员重置密码。

**Q: 微信登录失败？**
A: 请确保您已在个人中心完成了绑定操作，且微信号与当前设备一致。

**Q: 上传图片很慢？**
A: 请检查网络连接。系统支持断点续传，如果失败可以点击重试。

**Q: 列表/详情出现“加载失败”怎么办？**
A: 先点击页面内的“重试”。如连续 3 次失败，请联系管理员并提供大致时间、订单号和错误截图。

**Q: 提交失败后内容会丢吗？**
A: 不会。V2 默认保留当前输入，可直接重试提交。

**Q: 为什么订单详情里显示部分到货，但采购同事说采购单还没全部完成？**
A: 现在系统按实际收货进度展示订单采购状态。采购单可以分批到货，所以订单先显示“部分到货”是正常情况。
