# 销售端个人统计教程

- 页面路由：`/sales/:token/stats`
- 截图说明：以下示例按手机竖屏视口采集

![销售端个人统计](../../assets/user-manual/08-sales-stats.png)

## 页面用途

统计页用于查看当前销售员自己的订单数据概览。

## 页面里可以做什么

- 查看总订单数
- 查看已完成订单数
- 查看本月订单数
- 查看最近一段时间的简易趋势

## 适合回答的问题

- 我总共提交了多少订单
- 本月最近是否在持续出单
- 已完成订单占比大概怎样

## 常见排查

### 页面提示无数据

如果当前销售员本来就没下过单，空状态是正常的。

### 统计加载失败

先点重试，再确认当前登录态是否仍有效。
