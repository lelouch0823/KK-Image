# 销售端新建订单教程

- 页面路由：`/sales/:token/create`
- 截图说明：以下示例按手机竖屏视口采集

![销售端新建订单](../../assets/user-manual/06-sales-create.png)

## 页面用途

这个页面用于提交新的客户需求单，也就是销售端的主建单入口。

## 页面里可以做什么

- 先绑定商品和规格
- 自动带出商品基础信息
- 填写数量、备注、期望到货时间等字段
- 上传参考图片
- 提交订单
- 取消并返回列表

## 页面特点

绑定商品和规格后，部分字段会自动带出并锁定，减少手填错误。

当前页面的商品选择策略偏向：

- 优先选有库存或可售规格

## 推荐使用顺序

1. 先选商品和规格。
2. 确认自动带出的品牌、系列、SKU 是否正确。
3. 填数量、备注和附件。
4. 提交后返回订单列表确认已创建。

## 常见排查

### 商品拉取失败

页面会显示错误和重试按钮，先重试一次，再确认网络和商品数据是否可用。

### 提交后没看到新订单

先回列表手动刷新，再确认是否被当前搜索条件隐藏。

### 不知道该不该先上传图片

业务上建议上传参考图，便于后台和采购判断需求。
