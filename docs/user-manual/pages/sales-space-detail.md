# 销售端空间详情页教程

- 页面路由：`/sales/:token/spaces/:id`
- 截图说明：当前手册暂未单独附图，以下内容按真实页面行为整理

## 页面用途

这个页面用于查看某个销售端共享空间的实际内容。

它会根据空间模板自动切换展示方式，例如：

- 图库流
- 商品详情
- 集合页
- 文档页

## 页面里可以做什么

- 查看当前空间的标题、描述和素材
- 根据模板浏览商品图、文件或文档内容
- 继续进入下级空间

## 常见排查

### 页面提示无法加载

优先确认：

- 当前销售链接 `:token` 仍然有效
- 该空间仍然分配给当前销售员
- 空间没有过期或被删除

### 子空间打不开

通常表示该子空间已经过期、被取消授权，或后台还没补齐内容。
