# 微信小程序资源详情页教程

- 页面路径：`pages/spaces_detail/detail`

## 页面用途

资源详情页用于查看某一个共享资源的具体内容。

页面会根据资源模板展示不同布局，比如画廊、商品、作品集、文档或合集。

## 页面里可以做什么

- 预览图片
- 查看文档类内容
- 在合集模板里继续进入子资源
- 根据模板浏览不同类型的展示内容

## 常见排查

### 打开后没有内容

先确认后台是否已经给这个资源绑定文件。

### 文档打不开

先确认当前手机是否支持打开对应文件类型，再重试一次下载或打开。

### 合集里点子资源没有反应

先返回重进一次，如果仍异常，联系管理员确认子资源配置是否正常。
