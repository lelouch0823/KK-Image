# 微信小程序资源列表页教程

- 页面路径：`pages/spaces/spaces`

## 页面用途

这个页面用于查看后台分配给当前销售员的小程序资源卡片。

## 页面里可以做什么

- 浏览资源卡片
- 查看封面和文件数量
- 查看模板类型
- 点击进入资源详情页

## 推荐使用顺序

1. 进入资源页查看是否已有可展示资源。
2. 找到需要给客户展示的卡片。
3. 点击进入资源详情页继续查看内容。

## 常见排查

### 资源页为空

通常表示后台还没有把共享资源分配给当前销售员。

### 卡片点开后内容不对

联系管理员确认资源绑定内容、模板和封面是否已更新。
