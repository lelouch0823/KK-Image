# 微信小程序订单详情页教程

- 页面路径：`pages/detail/detail`

## 页面用途

订单详情页用于查看单笔订单的当前状态，并继续追加留言跟进。

## 页面里可以做什么

- 查看订单状态
- 查看图片
- 查看订单信息
- 查看时间轴
- 输入留言
- 复制当前订单进入新建页

## 推荐使用顺序

1. 先看当前状态和时间轴。
2. 有补充需求时直接留言。
3. 如果客户要在原单基础上再下一单，用复制功能进入新建页。

## 常见排查

### 留言发不出去

先确认网络是否稳定，再等待一次返回结果，不要连续重复点发送。

### 详情加载失败

先返回列表重新进入，再确认当前订单是否仍属于这个账号。
