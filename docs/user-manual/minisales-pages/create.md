# 微信小程序新建订单页教程

- 页面路径：`pages/form/form`

## 页面用途

这个页面用于在微信小程序里快速录入新的客户需求单。

## 页面里可以做什么

- 上传产品图片
- 填写客户名称
- 填写品牌、系列、尺寸、颜色、材质
- 选择期望到货日期
- 填写备注
- 提交订单

## 推荐使用顺序

1. 先上传产品图片。
2. 填客户名称和品牌。
3. 再补系列、尺寸、颜色、材质。
4. 需要时选择期望到货日期。
5. 确认上传完成后提交。

## 常见排查

### 提交按钮点了没反应

先确认必填字段是否已填写，再确认是否还有图片处于上传中。

### 图片上传失败

先删除失败项或重新上传，再继续提交订单。
