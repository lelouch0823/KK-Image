# 微信小程序统计页教程

- 页面路径：`pages/stats/stats`

## 页面用途

统计页用于查看自己在小程序侧对应账号下的订单概览。

## 页面里可以做什么

- 查看总订单数
- 查看已完成订单数
- 查看本月订单数
- 查看近期趋势

## 适合回答的问题

- 我最近有没有持续出单
- 这个月的订单大概有多少
- 已完成订单大概占多少

## 常见排查

### 页面没数据

如果当前账号订单本来就少，空数据或少量数据是正常的。

### 趋势图没有刷新

先下拉刷新一次，再重新进入统计页确认。
