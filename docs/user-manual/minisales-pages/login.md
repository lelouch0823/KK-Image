# 微信小程序登录页教程

- 页面路径：`pages/login/login`

## 页面用途

这是微信小程序销售端的登录入口。

当前页面默认展示账号密码登录表单，支持使用手机号或姓名登录。

## 页面里可以做什么

- 输入账号
- 输入密码
- 点击登录
- 在支持的环境里切换到后续业务页

## 推荐使用顺序

1. 输入手机号或姓名。
2. 输入密码。
3. 登录成功后进入订单列表页。

## 常见排查

### 提示账号或密码错误

先确认姓名 / 手机号是否输入正确，再确认密码是否已被管理员重置。

### 登录成功但没有进入业务页

先重开一次小程序，再确认当前账号是否仍启用。
