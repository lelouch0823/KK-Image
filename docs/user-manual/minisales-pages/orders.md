# 微信小程序订单列表页教程

- 页面路径：`pages/index/index`

## 页面用途

这是小程序登录后的默认首页，用于查看自己的订单、进入订单详情，以及新建订单。

## 页面里可以做什么

- 浏览订单卡片
- 查看订单状态
- 查看新反馈标记
- 下拉刷新
- 点击订单进入详情
- 点击右下角“+”进入新建订单

## 推荐使用顺序

1. 先看是否有带新反馈标记的订单。
2. 需要跟进时进入订单详情。
3. 需要录新单时，点击右下角“+”。

## 常见排查

### 列表为空

先确认当前账号是否确实还没有订单，空列表不一定代表异常。

### 找不到刚提交的订单

先下拉刷新，再重新确认是否已经提交成功。
