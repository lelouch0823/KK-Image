# 微信小程序销售端手册

本手册面向当前 `minisales` 微信小程序销售端，适合已经启用小程序交付的环境。

如果你所在环境还没有启用小程序，请继续使用 [销售端使用手册（移动端 Web）](sales-guide.md)。

如果你想按页面查操作，请继续看 [微信小程序逐页教程](minisales-pages/README.md)。

## 适用范围

- 小程序登录
- 订单列表
- 新建订单
- 订单详情与留言
- 个人统计
- 共享资源查看

## 使用前准备

开始前请先确认：

1. 你所在环境已经发布并启用了微信小程序销售端。
2. 你已经拿到账号和密码。
3. 如果要使用微信一键登录，后台已经配置微信登录能力，且当前账号已经绑定微信。

## 登录方式

当前小程序支持两种登录方式：

- 账号密码登录
  使用手机号或姓名加密码登录。
- 微信一键登录
  仅在当前环境启用微信能力，且账号已绑定微信时可用。

如果微信一键登录提示未绑定，请先改用账号密码登录，再由管理员协助完成绑定。

## 首页与底部标签

小程序底部通常有三个主标签：

- 订单
- 资源
- 统计

其中：

- “订单”页用于浏览自己的订单列表并进入详情
- “资源”页用于查看后台分配给自己的共享空间
- “统计”页用于查看个人订单数据

## 当前页面结构

当前小程序主要页面可以对应为：

- 登录页：`pages/login/login`
- 订单列表：`pages/index/index`
- 新建订单：`pages/form/form`
- 订单详情：`pages/detail/detail`
- 资源列表：`pages/spaces/spaces`
- 资源详情：`pages/spaces_detail/detail`
- 统计页：`pages/stats/stats`

如果业务同事在沟通中提到“订单页”“资源页”“统计页”，通常就是指这几类页面。

## 订单列表

订单列表页通常会显示：

- 订单卡片
- 订单状态
- 新反馈标记
- 右下角新建按钮

日常使用建议：

1. 先看有没有新反馈标记。
2. 再进入需要跟进的订单。
3. 需要录新需求时，点击右下角“+”。

如果列表为空，先确认当前账号是否确实还没有订单。

## 新建订单

小程序端新建订单更适合快速录单，当前主要依赖手工填写。

常见填写顺序：

1. 先上传产品图片。
2. 填客户名称和品牌。
3. 再补系列、尺寸、颜色、材质。
4. 需要时选择期望到货日期。
5. 填备注后提交。

当前小程序表单里最关键的必填信息至少包括：

- 客户名称
- 品牌

使用时要注意：

- 图片上传完成前不要急着提交。
- 如果存在上传失败图片，先处理失败项再提交。
- 提交成功后页面通常会自动返回上一页。

## 订单详情

订单详情页主要用于跟进已有订单，而不是重新录单。

你可以在详情页完成这些操作：

- 查看订单状态
- 查看商品图片
- 查看订单信息
- 查看时间轴
- 追加留言
- 复制当前订单进入新建页

如果客户只是小幅改动要求，优先通过留言补充；如果客户需求已经明显变化，建议直接复制一单再重新提交。

## 个人统计

统计页适合快速查看自己的出单情况。

通常可以看到：

- 总订单数
- 已完成订单数
- 本月订单数
- 近期趋势

它更适合复盘，不适合处理具体订单。

## 共享资源

“资源”页用于查看后台分配给你的共享空间。

常见使用方式：

1. 进入“资源”标签页。
2. 找到需要展示的资源卡片。
3. 点进详情后预览图片、文档或合集内容。
4. 再向客户展示对应内容。

如果这里没有任何资源，通常表示后台还没有给当前销售员分配展示空间。

## 推荐日常流程

如果你主要用小程序办公，日常顺序建议固定为：

1. 先打开订单列表，看有没有新单或待跟进订单。
2. 需要录单时，直接点“+”进入新建订单。
3. 提交后回列表确认新单是否已出现。
4. 客户有追问时，进入订单详情补留言。
5. 需要给客户展示素材时，再切到“资源”页。

这样做的好处是：

- 先看存量订单，再决定是否新建
- 上传图片和录单动作更集中，不容易漏
- 展示资源与订单跟进不会混在一起

## Web 与小程序的区别

当前两条销售端入口并不完全等价：

- Web 销售端更适合按链接登录、查看通知、按当前 Web 页面流程协同处理
- 小程序更适合日常手机内快速录单和跟进

当前小程序侧和 Web 侧的一个重要差异是：

- Web 销售端已经有更完整的页面化教程和截图
- 小程序侧当前更偏“轻量录单 + 跟进”
- 小程序底部固定是“订单 / 资源 / 统计”三段式入口
- Web 销售端则更适合沿着页面路由逐页讲解和培训

如果你发现两个入口的页面布局不一样，这是正常现象，不代表功能异常。

## 常见问题

### 小程序登录失败

- 先确认手机号 / 姓名和密码是否正确
- 再确认当前账号是否仍启用

### 微信一键登录不可用

- 先确认当前环境是否启用了微信登录
- 再确认账号是否已经绑定微信

### 图片一直上传中

- 先检查网络是否稳定
- 上传完成前不要退出当前页面

### 订单提交失败

- 先确认必填字段是否已填写
- 再确认失败图片是否已经移除或重传成功

### 资源页为空

- 联系管理员确认是否已分配共享空间
