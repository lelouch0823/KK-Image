## 🌟 核心特性

### 高性能存储
- **极速访问** - 基于 Cloudflare R2 + CDN，全球毫秒级响应
- **高可靠性** - 企业级对象存储，数据持久化保障
- **灵活扩展** - 支持从个人博客到企业级应用的平滑扩展

### 多格式支持
- **图片格式** - JPG, PNG, GIF, WebP, SVG 等
- **媒体格式** - MP4, WebM (支持流式播放)
- **文档格式** - PDF, DOCX 等办公文档
- **智能处理** - 图片自动压缩/WebP 转换 (视配置而定)

### 智能管理
- **三种视图** - 列表视图、网格视图、瀑布流视图
- **批量操作** - 支持批量删除、复制链接等操作
- **搜索功能** - 按文件名、上传时间等条件搜索
- **状态管理** - 审核状态、黑白名单管理

## 🔧 使用前准备

### 访问地址
确保您知道正确的访问地址：
- **主站地址** - 您的 kk-life 部署域名
- **后台地址** - `您的域名/admin`（需要管理员权限）

### 浏览器要求
推荐使用以下浏览器以获得最佳体验：
- **Chrome** 90+ （推荐）
- **Firefox** 88+
- **Safari** 14+
- **Edge** 90+

### 网络要求
- **稳定网络连接** - 确保网络连接稳定
- **合理网速** - 上传大文件时需要足够的上传带宽
- **防火墙设置** - 确保可以访问 Cloudflare 服务

## 📱 移动端使用

kk-life 支持移动端访问：

- 支持主流移动浏览器

## 🔒 隐私和安全

### 数据安全
- **传输加密** - 全站 HTTPS 加密传输
- **存储安全** - 数据存储于 Cloudflare R2，私有读写权限控制
- **访问控制** - 基于 JWT/Token 的多级权限管理

### 隐私保护
- **匿名上传** - 支持无痕上传（视配置开启）
- **内容审查** - 接入 AI 内容审查，过滤违规内容

## 📊 使用限制

### Cloudflare 限制
- **文件大小** - 默认支持 100MB+ 单文件 (取决于 R2 配置)
- **请求频率** - 遵循 Cloudflare 平台速率限制保护
- **存储容量** - 取决于您绑定的 R2 套餐 (免费额度 10GB/月)

### 使用建议
- **合理使用** - 避免托管违规内容
- **定期备份** - 建议定期导出重要数据
