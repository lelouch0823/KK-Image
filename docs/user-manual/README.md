# 用户手册

本手册面向当前系统的业务使用者，覆盖管理端文件使用、销售端下单和预订单协同等现行流程。

## 适用对象

- 管理端业务人员
- 销售人员
- 运营 / 采购协同同事

## 当前使用入口

- 管理端：`/admin`
- 销售端门户：`/sales/:token`
- 微信小程序销售端：`minisales/`（已启用该交付形态的环境）
- 共享空间：`/space/:token`

## 怎么选入口

- 需要管理文件、空间、商品、订单后台：用管理端
- 销售同事通过手机浏览器跟进订单：优先用 Web 销售端
- 已启用微信小程序并希望在微信内快速录单：用小程序销售端

## 说明

- 根路径 `/` 默认不会直接进入公开上传页，而是跳转到 `/login`
