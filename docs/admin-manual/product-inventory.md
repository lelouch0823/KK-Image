# 商品与库存管理

欢迎使用 KK-Image 的商品与库存管理模块！此部分致力于帮助您可以高效、精准地管理库存流派、商品的多个规格（SKU）以及从海外下单到入库的全链路采购追踪。

## 📦 商品管理 (Products & Variants)

在**商品管理**系统里提供商品 (SPU) 和具体变体 (SKU) 的分层管理：

- **SPU (标准产品单位)**：适用于同款商品，可设置商品名称、分类、品牌、所属空间（支持为不同供应商/合伙人隔离）等基础信息，以及对应的富文本或图片描述。
- **SKU (变体)**：基于不同规格（如颜色、款式、容量等）来为商品配置独立的价格、成本价及库存状况。每个 SKU 都具有唯一的编码。

### 批量导入功能
如果有大量的规格库，系统提供了 **CSV/Excel 批量导入** 功能。系统将按 SPU 名称及特定维度进行自动聚合，对同名商品追加 SKU 或对现有 SKU 执行价格/库存的 Upsert (更新或插入)。

## 🚚 采购单管理 (Purchase Orders)

采购单生命周期包括从“选品”到“最终入库”等阶段的跟踪，方便海外货源代购、直邮场景下的头程及物流成本管理：

### 状态流转
- **草稿 (Draft)**：创建阶段，正将准备购买的不同商品变体积聚在一起。
- **已下单 (Ordered)**：代表已经在供货商（如海外官网）处成功下单。
- **运输中 (Shipping)**：发往国内的国际/本土物流阶段，需要注意填报预计运费。
- **已到货 (Arrived)**：货物抵达仓库。此时确认入库，将促使相应 SKU 的**实际库存**立刻增加。
- **已结算 (Settled/Completed)**：财务环节，输入实际发生的运费和关税后，系统支持「按数量」或「按金额」进行运费成本的同比例自动拆摊。

## 📊 订货总览 (Goods Overview)

针对高转速商品的缺货问题，系统内嵌的**订货总览视图**能进行：
- **实时在途统计**：横向对比特定 SKU 的现有物理库存、被订单占用的“待发货库存”，以及采购单维度正处于“已下单”或“运输中”的在途数量。
- **库存预警生成**：根据过去X周的平均销量或安全阈值提示补货，可在此处直接勾选缺货 SKU 快速一键生成关联“草稿采购单”。

## 📕 存货账本 (Inventory Ledger)
每一次的库存增减（如：采购到货、客单发货、以及后台管理员的直接调整）均会不可逆地记录在 **Inventory Ledger** (库存流水日记账)中，以确保账实相符并追溯每笔出入库流水。
