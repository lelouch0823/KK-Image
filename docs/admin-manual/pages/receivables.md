# 应收看板页面教程

- 页面路由：`/admin/receivables`
- 典型权限：`orders:read`
- 默认导航：可注册为后台页面，但不一定在侧边栏或命令面板中显示

## 页面用途

应收看板用于查看订单金额、已收款和未收余额的汇总情况。

## 页面里可以做什么

- 查看应收总览
- 查看账龄分析
- 查看欠款客户排行
- 辅助定位需要跟进收款的订单和客户

## 推荐使用顺序

1. 先看应收总额和逾期情况。
2. 再看欠款客户排行。
3. 进入 [订单管理](orders.md) 或客户详情核对单据。
4. 在订单详情维护付款记录。

## 关键语义

- 应收看板由订单金额和 `payments` 付款记录聚合而来。
- 付款记录属于订单详情下的事实记录。
- 已归档订单不能继续新增或删除付款记录。
