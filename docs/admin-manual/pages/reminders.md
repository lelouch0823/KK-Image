# 提醒中心页面教程

- 页面路由：`/admin/reminders`
- 典型权限：`notifications:read`

## 页面用途

提醒中心用于集中查看待跟进的系统通知、订单提醒和高风险运维提示。

## 页面里可以做什么

- 查看未读提醒数量
- 刷新提醒列表
- 单条标记已读
- 全部标记已读
- 快速识别高风险提醒，例如审计导出告警

## 推荐使用顺序

1. 先看顶部未读数，确认今天是否有堆积。
2. 优先处理高风险或未读提醒。
3. 已经核对过的提醒再标记已读，避免把业务异常当成已解决。

## 常见排查

### 看不到提醒列表

先检查当前账号是否具备 `notifications:read`。

### 导出审计后想确认有没有留下提示

导出成功后，提醒中心会新增一条管理员提醒，标题和摘要会说明导出数量与时间。
