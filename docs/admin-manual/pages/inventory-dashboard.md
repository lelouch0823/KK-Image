# 库存仪表盘页面教程

- 页面路由：`/admin/inventory-dashboard`
- 典型权限：`products:manage`
- 默认导航：可注册为后台页面，但不一定在侧边栏或命令面板中显示

## 页面用途

库存仪表盘用于快速观察当前库存风险，不是商品维护页，也不是盘点录入页。

## 页面里可以做什么

- 查看库存 SKU 总量
- 查看低库存和零库存数量
- 查看库存总价值
- 查看低库存 / 零库存列表
- 查看最近库存变动
- 查看近 30 天出库排行

## 推荐使用顺序

1. 先看摘要卡片判断整体风险。
2. 再看低库存和零库存列表定位 SKU。
3. 对异常 SKU 回到 [商品管理](products.md) 或 [库存盘点](stocktakes.md) 继续处理。
4. 若异常来自订单或采购流转，回到 [订单管理](orders.md) 和 [采购单管理](purchase-orders.md) 对照事实链路。

## 常见排查

### 库存数字看起来不对

先查最近库存变动，再看采购收货、冲销和订单出货是否刚发生过。

### 低库存列表为空

确认商品规格是否设置了预警阈值，以及当前筛选权限是否覆盖这些商品。
