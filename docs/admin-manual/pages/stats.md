# 统计分析页面教程

- 页面路由：`/admin/stats`
- 典型权限：`stats:read`

![统计分析](../../assets/admin-manual/10-stats.png)

## 页面用途

统计页用于看趋势，不用于处理单笔业务。

当前页面会展示：

- 文件总量
- 总存储占用
- 当月访问量
- 流量趋势
- 文件类型分布
- 热门空间排行
- 系统状态概览
- 大文件列表

## 页面里可以做什么

- 刷新统计
- 看核心卡片
- 读趋势图和分布图
- 找到最近曝光最多的空间
- 识别异常大文件

## 推荐使用顺序

1. 先看顶部核心指标。
2. 再看趋势图判断变化方向。
3. 再看热门空间和状态概览。
4. 最后用大文件表排查占用异常。

## 常见排查

### 运营想看周报或月报趋势

这个页面比仪表盘更适合做趋势复盘。

### 怀疑有异常大文件占空间

直接看大文件列表，不要只看总存储值。

### 页面提示无权限

先检查当前账号是否具备 `stats:read`。
