# 系统设置页面教程

- 页面路由：`/admin/settings`
- 典型权限：`admin:full`

![系统设置](../../assets/admin-manual/11-settings.png)

## 页面用途

设置页负责系统级配置，当前分为三个标签：

- AI
- Watermark
- Backups

## 页面里可以做什么

### AI

- 配置 API 地址和 Key
- 拉取模型列表
- 调整模型优先级
- 开关动态回退
- 测试连接
- 查看模型健康统计

### Watermark

- 开关水印
- 设置文案、位置、透明度、颜色、字号比例

### Backups

- 查看备份列表
- 创建备份
- 下载备份

## 推荐使用顺序

1. 先确认本次改的是哪一类配置。
2. 改完 AI 后先做连接测试。
3. 改完水印后做一次真实上传验证。
4. 做高风险变更前先创建备份。

## 常见排查

### AI 配了但功能还是不通

先在设置页做连接测试，再回真实 AI 功能页复核。

### 改了水印但旧图没变化

当前水印影响的是新上传图片，不会回写历史文件。

### 想删除备份

后台有删除能力，但当前页面没有提供按钮，不建议把删除当成日常操作。
