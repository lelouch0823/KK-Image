# 库存盘点页面教程

- 页面路由：`/admin/stocktakes`
- 典型权限：`products:manage`
- 默认导航：可注册为后台页面，但不一定在侧边栏或命令面板中显示

## 页面用途

库存盘点页用于把人工盘点结果落成可追溯的库存调整。

## 页面里可以做什么

- 创建盘点单
- 查看盘点单列表和状态
- 打开盘点单详情
- 录入实际盘点数量
- 更新盘点备注
- 执行库存调整
- 取消盘点单

## 推荐使用顺序

1. 在 [库存仪表盘](inventory-dashboard.md) 或商品页定位异常 SKU。
2. 创建盘点单。
3. 按明细录入实际数量和备注。
4. 复核差异后执行调整。
5. 回到库存仪表盘或商品详情确认读模型刷新。

## 关键语义

- 盘点单不是直接改库存结果值。
- 执行调整后，应通过库存服务写入库存事实，再刷新读模型。
- 已取消盘点单不应继续用于调整。
