# 商品管理页面教程

- 页面路由：`/admin/products`
- 典型权限：`products:manage`

![商品管理](../../assets/admin-manual/04-products.png)

## 页面用途

商品页是商品主数据入口，适合维护商品、查看详情、导入导出以及从商品快速创建展示空间。

## 页面里可以做什么

- 按关键字、状态、品牌、分类、库存条件筛选商品
- 新建商品
- 导入商品
- 导出商品
- 查看商品统计弹窗
- 点击行进入商品详情
- 在详情里切换到编辑
- 快捷分享，把商品直接带入空间创建
- 删除商品

## 推荐使用顺序

1. 先用筛选确定是新增、编辑还是批量整理。
2. 新建或编辑时优先把基础资料和规格维护完整。
3. 需要给销售快速展示时，直接用“分享”动作创建商品空间。
4. 需要采购或看缺口时，再转到 [订货总览](goods-overview.md)。

## 适合回答的问题

- 商品是否已经建档
- 某品牌或分类下有哪些商品
- 某商品库存状态是否异常
- 这个商品能否直接生成展示空间

## 常见排查

### 商品能看详情，但编辑加载失败

通常是详情快照不完整，页面会补做完整 hydration。重试仍失败时再检查该商品数据本身。

### 想给销售看商品，但没找到分享入口

行内的“分享”会打开空间创建流程，不是直接发文件链接。

### 导入后列表没看到新商品

先清空当前筛选，再刷新列表，不要在旧筛选条件下直接判断导入失败。

### 商品上下架状态看起来不一致

商品列表状态按规格聚合：至少一个规格 active 时商品显示 active；所有规格归档后才显示 archived。批量规格上下架、库存或收货变化后，系统会刷新商品投影和缓存。
