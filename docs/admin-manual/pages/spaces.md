# 空间管理页面教程

- 页面路由：`/admin/spaces`
- 典型权限：`spaces:read`

![空间管理](../../assets/admin-manual/03-spaces.png)

## 页面用途

空间页负责组织“对外展示容器”，不是简单存放文件。

当前页面适合做：

- 创建展示空间
- 删除空间
- 打开空间详情继续维护
- 查看封面、文件数、浏览量和分享范围

## 页面里可以做什么

- 新建顶级空间
- 选择模板 `gallery`、`product`、`collection`、`document`、`portfolio`
- 查看当前空间的分享模式
- 进入空间详情后管理文件、设置和分析

## 空间详情里的重点

当前详情页有三个标签：

- 文件
  - 添加文件、移除文件、设置封面
- 设置
  - 发布 / 取消发布
  - 调整 `shareMode`
  - 查看分享链接和浏览量
- 分析
  - 查看空间访问分析

如果是 `collection` 模板，文件标签会变成子空间列表。

## 推荐使用顺序

1. 先在 [文件管理](files.md) 把素材整理好。
2. 再创建合适模板的空间。
3. 进入详情补文件、封面和分享模式。
4. 确认无误后再发布和预览。

## 常见排查

### 销售反馈看不到空间内容

依次检查：

1. 空间是否已发布
2. `shareMode` 是否正确
3. 指定销售员是否真的在共享范围内

### 能打开空间详情但不能编辑

通常是当前账号没有 `spaces:manage`。

### 预览按钮点了没打开内容

未发布的空间还没有可用的 `shareToken`，需要先发布。
