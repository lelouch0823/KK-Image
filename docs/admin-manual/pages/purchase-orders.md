# 采购单管理页面教程

- 页面路由：`/admin/purchase-orders`
- 当前后台导航通常由商品 / 采购管理权限控制

![采购单管理](../../assets/admin-manual/07-purchase-orders.png)

## 页面用途

采购单页负责把补货需求落成可执行单据，并跟踪状态、收货、冲销和成本分摊。

## 页面里可以做什么

- 查看各状态统计卡
- 打开采购建议弹层
- 新建采购单
- 点击列表行进入详情
- 在详情里修改采购单状态
- 记录收货
- 对收货执行冲销
- 保存成本设置并执行成本分摊

## 推荐使用顺序

1. 先通过 [订货总览](goods-overview.md) 确定缺口。
2. 再到采购单页新建或处理现有采购单。
3. 到货后优先记录收货，而不是只改头状态。
4. 对账后再补运费、关税并执行成本分摊。

## 详情页重点

当前详情里最关键的动作有三类：

- 状态流转
  - 草稿、已下单、运输中、到货、完成、取消
- 收货台账
  - 支持部分到货
  - 支持对单条收货做冲销
- 成本设置
  - 保存运费 / 关税等参数
  - 需要时手动执行成本分摊

## 常见排查

### 采购单已到货，但订单还是部分完成

当前真实推进依赖收货记录，不是只看采购单头状态。

### 收货录错了怎么办

不要改历史事实，直接用收货冲销回退。

### 为什么详情里还要做成本分摊

收货和成本是两条线。收货先解决库存与履约，分摊再解决财务口径。
