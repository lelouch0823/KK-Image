# 订货总览页面教程

- 页面路由：`/admin/goods-overview`
- 当前后台导航通常由商品 / 采购管理权限控制

![订货总览](../../assets/admin-manual/06-goods-overview.png)

## 页面用途

订货总览是缺口判断页，不是普通商品列表。

它把当前需求、库存、在途和缺口汇总到规格级视角，适合采购前先做优先级排序。

## 页面里可以做什么

- 按品牌、分类过滤
- 只看缺货项
- 按缺口、需求、名称、成本排序
- 查看各状态管道汇总卡片
- 查看库存、总需求、缺口和成本字段
- 勾选多项后直接生成采购单
- 导出 CSV

## 推荐使用顺序

1. 先看顶部管道卡和总需求摘要。
2. 再打开“仅看缺货”过滤器。
3. 按缺口排序，先处理最急的规格。
4. 勾选需要补货的条目，直接生成采购单。

## 适合回答的问题

- 现在最缺哪些规格
- 哪些需求已经被在途覆盖
- 该先补哪一批货
- 选中的缺货项能不能直接落成采购单

## 常见排查

### 采购同事问“先买什么”

先开这个页面，不要直接凭订单数量判断。

### 看到缺口，但不确定采购是否已经创建

生成采购单后会跳转到 [采购单管理](purchase-orders.md) 对应单据继续处理。

### 某规格不在列表里

先检查品牌 / 分类 / 缺货过滤是否把它排除了。
