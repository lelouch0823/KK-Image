# 销售员管理页面教程

- 页面路由：`/admin/salespersons`
- 典型权限：查看 `users:read`，写操作 `users:write`

![销售员管理](../../assets/admin-manual/09-salespersons.png)

## 页面用途

销售员页负责维护业务入口账号，不直接处理订单履约。

## 页面里可以做什么

- 搜索销售员
- 新建销售员
- 编辑销售员资料
- 打开详情弹窗
- 复制销售入口链接
- 跳转查看该销售员相关订单
- 重置访问 token
- 在无关联订单时删除销售员

## 推荐操作顺序

1. 新建销售员并补齐姓名、门店、电话、初始密码。
2. 复制入口链接分发给对应人员。
3. 如果反馈订单异常，直接从这里跳转到订单页定位。
4. 如发生链接泄露或交接，再执行重置 token。

## 常见排查

### 销售链接失效

先看该销售员是否被停用或重置过 token。

### 想删除销售员但按钮不可用

当前销售员若已有关联订单，不应直接删除，优先停用或重置。

### 只能看列表不能新建

通常是只有 `users:read` 没有 `users:write`。
