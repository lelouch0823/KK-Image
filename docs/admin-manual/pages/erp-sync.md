# ERP 同步页面教程

- 页面路由：`/admin/erp-sync`
- 典型权限：`admin:full`
- 默认导航：隐藏入口，适合管理员或集成维护人员使用

## 页面用途

ERP 同步页用于管理外部 ERP 连接、触发同步和查看同步日志。

## 页面里可以做什么

- 创建、查看、更新或删除 ERP 连接
- 测试连接
- 触发商品、客户、订单同步
- 查看同步日志
- 查看实体映射
- 接收 ERP webhook 回调

## 推荐使用顺序

1. 在预览环境创建连接并测试。
2. 先同步少量实体，确认映射和日志。
3. 再扩大到完整同步。
4. 出现失败时优先看同步日志和实体映射，不要直接重跑全量同步。

## 安全边界

- 连接管理需要 `admin:full`。
- Webhook 回调通过签名验证，不按普通管理员会话鉴权。
- 外部 URL 会经过安全校验，避免把内部地址配置成 ERP base URL。
