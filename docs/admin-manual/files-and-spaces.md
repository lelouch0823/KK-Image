# 文件与空间管理

本文档面向运营、商品维护和管理员，说明当前后台里“文件管理”和“空间管理”的分工、权限和推荐操作顺序。

相关页面：

- 文件管理：`/admin/files`
- 空间管理：`/admin/spaces`

![文件管理](../assets/admin-manual/02-files.png)

![空间管理](../assets/admin-manual/03-spaces.png)

## 1. 先分清两个页面的职责

文件页负责“资料本身”：

- 上传原始图片和文档
- 建目录、整理层级
- 批量移动、删除、打标签
- 处理文件和文件夹的分享

空间页负责“对外展示容器”：

- 创建展示空间和子空间
- 绑定封面图与展示文件
- 控制销售可见范围
- 生成预览和分享入口

判断原则：

- 只是把素材收进系统，先去文件页
- 需要给销售、客户或公开页展示内容，去空间页

## 2. 权限边界

文件页常见权限：

- 查看文件：`files:read`
- 上传、重命名、打标签：`files:write`
- 删除文件：`files:delete`
- 查看文件夹：`folders:read`
- 新建、重命名、分享文件夹：`folders:write`
- 删除文件夹：`folders:delete`

空间页常见权限：

- 查看空间：`spaces:read`
- 创建、编辑、删除空间：`spaces:manage`

如果页面能看但按钮灰掉，通常不是数据问题，而是当前账号缺少对应写权限。

## 3. 推荐日常操作顺序

1. 先在文件页上传并整理原始资料。
2. 用文件夹划分系列、品牌、活动或客户主题。
3. 需要批量整理时，再执行批量移动、批量删除或批量打标签。
4. 素材稳定后，到空间页新建展示空间。
5. 在空间详情里补文件、封面和销售可见性。
6. 最后再做预览或分发分享链接。

这个顺序可以避免“空间已经发出，但素材还在反复搬动”的问题。

## 4. 文件管理页可以做什么

当前文件页支持的核心动作：

- 在当前目录上传文件
- 新建文件夹
- 通过面包屑切换目录
- 列表视图 / 网格视图切换
- 搜索当前结果
- 批量移动、批量删除、批量打标签
- 单文件分享、下载、重命名、删除
- 单文件夹分享、移动、重命名、删除
- 打开回收站处理已删除项目

实务建议：

- 商品图、活动图、客户资料先按文件夹分组，再做后续空间绑定
- 批量操作前先清空错误选择，避免跨目录误删
- 分享动作适合临时资料分发；需要稳定展示入口时，优先用空间
- 文件缺失、顺序混乱或找不到原图时，第一站先回到这里

## 5. 空间管理页可以做什么

当前空间卡片页支持：

- 创建顶级空间
- 打开空间详情或管理页
- 删除空间
- 查看封面、文件数、浏览量
- 识别当前分享范围

创建空间时，当前可选模板包括：

- `gallery`
- `product`
- `collection`
- `document`
- `portfolio`

其中：

- `product` 适合商品展示，创建时可直接绑定商品
- `collection` 适合做系列集合，详情里会以子空间方式组织内容

## 6. 销售可见性和公开状态

空间当前有两层可见性概念：

- `isPublic`
  - 是否生成公开访问状态
- `shareMode`
  - 销售可见范围，当前支持 `none`、`selected`、`all`

推荐理解方式：

- `none`
  - 不给任何销售可见
- `selected`
  - 只给指定销售员可见
- `all`
  - 对所有销售员开放

如果销售反馈“链接能打开但看不到内容”，优先检查：

1. 空间是否已发布
2. `shareMode` 是否正确
3. 指定销售员是否真的在共享名单中

## 7. 空间详情里的三个标签页

空间详情当前分为三个标签：

- 文件
  - 添加文件、移除文件、设置封面
  - `collection` 模板下这里会变成子空间列表
- 设置
  - 发布 / 取消发布
  - 调整分享模式和销售员名单
  - 查看分享链接和浏览量
- 分析
  - 查看该空间的访问分析

注意：

- 预览依赖 `shareToken`
- 还没发布的空间直接点“预览”会收到提示，而不是直接生成可访问链接

## 8. 典型场景

### 销售页缺图

1. 先到文件页确认原图是否已上传。
2. 再到空间详情确认文件是否已经加入空间。
3. 最后检查封面图和分享范围。

### 新活动要快速建展示页

1. 文件页上传活动素材。
2. 空间页新建 `gallery` 或 `collection` 空间。
3. 在详情里补文件、封面和可见范围。
4. 发布后再发预览或分享链接。

### 商品想做专属展示空间

1. 确认商品主数据已存在。
2. 创建 `product` 模板空间并绑定商品。
3. 进入详情继续补图、封面和销售权限。
